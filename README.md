# alf89/cb

Laravel-пакет для получения актуальных курсов валют через API Центрального банка Российской Федерации.

Пакет предоставляет простой интерфейс для получения курса конкретной валюты или списка всех доступных валют.

## Возможности

* Получение курса конкретной валюты по коду.
* Получение курсов всех доступных валют.
* Удобный доступ через Laravel Facade.
* Использование Laravel HTTP Client.

## Требования

* PHP `^8.5`
* Laravel 9, 10, 11, 12 или 13.

## Установка

Установите пакет через Composer:

```bash
composer require alf89/cb
```

Laravel автоматически обнаружит и зарегистрирует `CbServiceProvider`.

После установки пакет готов к использованию.

## Использование

Пакет предназначен для использования через Facade.

### Получение курса валюты

```php
use alf89\cb\Facades\Cb;

$usd = Cb::currency('USD');
```

Например:

```php
$usd = Cb::currency('USD');

echo $usd['CharCode'];
echo $usd['Name'];
echo $usd['Value'];
```

Результат:

```php
[
    'ID' => 'R01235',
    'NumCode' => '840',
    'CharCode' => 'USD',
    'Nominal' => 1,
    'Name' => 'Доллар США',
    'Value' => 79.5671,
    'Previous' => 79.1234,
]
```

> Значения `Value` и `Previous` приведены только для примера и изменяются в зависимости от актуального курса.

### Получение всех валют

```php
use alf89\cb\Facades\Cb;

$currencies = Cb::currencies();
```

Получить конкретную валюту из результата:

```php
$usd = $currencies['USD'];
$eur = $currencies['EUR'];
```

## Методы

### `currency(string $code)`

Возвращает данные конкретной валюты по её коду.

```php
$usd = Cb::currency('USD');
```

Параметры:

| Параметр | Тип      | Описание                                 |
| -------- | -------- | ---------------------------------------- |
| `$code`  | `string` | Код валюты, например `USD`, `EUR`, `CNY` |

Возвращаемый массив содержит:

| Поле       | Описание             |
| ---------- | -------------------- |
| `ID`       | Идентификатор валюты |
| `NumCode`  | Цифровой код валюты  |
| `CharCode` | Буквенный код валюты |
| `Nominal`  | Номинал              |
| `Name`     | Название валюты      |
| `Value`    | Текущий курс         |
| `Previous` | Предыдущий курс      |

Пример:

```php
$eur = Cb::currency('EUR');

echo $eur['Value'];
```

### `currencies()`

Возвращает данные всех доступных валют.

```php
$currencies = Cb::currencies();
```

Ключом массива является буквенный код валюты:

```php
$currencies['USD'];
$currencies['EUR'];
$currencies['CNY'];
```

## Обработка ошибок

При неуспешном HTTP-запросе пакет выбрасывает `Exception`.

```php
use alf89\cb\Facades\Cb;

try {
    $usd = Cb::currency('USD');
} catch (\Exception $e) {
    // Обработка ошибки
}
```

## Архитектура

```text
src/
├── CbServiceProvider.php
├── Facades/
│   └── Cb.php
└── Services/
    ├── CurrencyService.php
    └── CurrencyApiClient.php
```

### `Cb`

Facade является публичной точкой входа в пакет:

```php
Cb::currency('USD');

Cb::currencies();
```

### `CurrencyService`

Отвечает за работу с данными валют.

### `CurrencyApiClient`

Отвечает за HTTP-запрос к внешнему API.

### `CbServiceProvider`

Регистрирует компоненты пакета в Laravel Service Container.
